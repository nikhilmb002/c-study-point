#include <stdio.h>
void abc(void);
void def(void);
void main() {

	int i = 10, j = 20;
	abc();
}

void abc(void) {

	int k = 30, l = 40;
	def();
}

void def(void) {

	int m = 10, n = 60;
}


/* 

    ^	|-------------------------------|
    |	|	i = 10, j = 20		| <--- stack for main, 1st stack
    |	|-------------------------------| 
    |	|	k = 30, l = 40		| <--- stack for abc, 2nd stack
	|-------------------------------|
  8 MB	|	m = 10, n = 60		| <--- stack for def, 3rd stack 
  stack |-------------------------------|
    |	|				|
    |	|				|	Last in First out 
    |	|				|		
    |	|				|
    |	|				|
    |	|				|		
    -	|-------------------------------|


In the above example program when _start calls the main then main function stack frame gets created. 
In that stack frame i & j variables memory gets allocated.
When main calls abc then abc function stack frame gets started. 
In that stack frame k & l variables memory gets allocated. 
When abc calls def then def function stack frame gets created. 
In that stack frame m and n variables memory gets allocated. 

*/
