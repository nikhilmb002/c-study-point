Recursive function
------------------

In one function defnition if the same function gets called such functions are called as recursive functions. 
When one function is calling the other function, before the other function begins internally 4 steps takes place

	1. The return address is pushed into the stack. 
	2. Function stack frame is created. 
	3. Auto variables & formal arguments and memory gets created. 
	4. Program counter is filled with 1st instruction of that function then that function execution begins.

Once the function execution completes : 

	1. The stack frame of that function is destroyed. 
	2. The return address is poped from the stack. 
	3. The program counter is updated with the return address. 
	4. Execution continues from the next instruction in the calling function.
